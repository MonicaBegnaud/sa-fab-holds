# SA-FAB-HOLDS
**Senior Capstone Project-CMPA-4304**

## Overview
SA FAB HOLDS is a web application prototype that I designed to solve a daily problem in my workplace: the lack of a centralized system to track production material (lots) that are in a "hold" state and not moving through the process flow. My application gives the user an easy to read dashboard with current held lot information, additional detail pages for individual lots, and key performance metrics. 

This project was build using HTML and CSS and is hotsed on GitHub pages. 

## Live Site
[SA FAB HOLDS](https://monicabegnaud.github.io/sa-fab-holds/)

## How to Navigate
### Dashboard
The main page a user will see when loading the site. There are five metric cards at the top for a quick status overview of our work site. Below the KPIs is a helf lot list with sample data that a user would need to address the held lot. 

### Lot Details
Currently additional lot details are only linked to the ID LOT-10001. Clicking on the lot ID will direct to a secondary page with a full record of just that lot.
